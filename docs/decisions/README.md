# Decision records

Short, numbered notes for decisions that are not obvious from the code: why a sensor is used
this way, why a rover command was added, why a pin was chosen for the CAM link.

Template:

```
# ADR-NNNN: <title>
Date · Status (proposed / accepted / superseded by ADR-MMMM)
## Context   – what forced the decision, measurements if any
## Decision  – what we do
## Consequences – what it costs, what it rules out
```

Keep them to half a page. A decision without a measured reason is a guess; say so.
